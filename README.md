# Приложение «Лифт»

Одноэкранное web-приложение-симулятор лифта:
- слева — внешний контроллер (вызов на этаж);
- по центру — шахта и кабина лифта с плавным движением и открытием/закрытием дверей;
- справа — внутренний контроллер (этажи, открыть/закрыть двери, отмена, связь с диспетчером).

## Запуск

### Вариант 1: просто открыть файл
Откройте `index.html` в браузере.

### Вариант 2 (рекомендуется): через локальный сервер
В папке проекта выполните:

```bash
python3 -m http.server 8080
```

После этого откройте в браузере:

```text
http://localhost:8080
```

## Управление

- **Вызов / Этаж N** — поставить заявку на этаж.
- **Открыть двери** — ручное открытие дверей (когда лифт стоит).
- **Закрыть двери** — ручное закрытие дверей (когда лифт стоит).
- **Отмена** — очистить очередь заявок.
- **Связь с диспетчером** — кнопка `tel:+78005553535`.
